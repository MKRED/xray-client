# Xray Client

Личный VPN-клиент для Android на Kotlin + Jetpack Compose с ядром Xray. Только для себя, в магазины не публикуется.

Поддерживаемые ссылки: `vless://` (в том числе Reality), `vmess://`, `trojan://`, `ss://`. Транспорты: tcp/raw, ws, grpc, httpupgrade, xhttp (h2/http приводятся к xhttp).

## Что умеет

### Источники
- **Подписки** — ссылка на подписку (base64 или список ссылок), обновление вручную и при запуске, если данные старше 6 часов. Трафик и срок из заголовка `subscription-userinfo`.
- **Свои серверы** — добавление по ссылке, QR-код для передачи на другое устройство.
- Исключение отдельных серверов подписки; отключение подписки целиком (список серверов при этом можно обновлять).
- Запрет теста скорости для подписки или сервера — для тарифов с лимитом трафика.

### Выбор сервера
- **Режимы**: *Быстрый / Лучший* — лучший по метрике; *Приоритет* — по блокам; *Вручную* — только выбранный.
- **Метрика** (одна на всё приложение):
  - *Задержка* — только пинг. Переключение, если другой сервер быстрее на 30% и больше чем на 50 мс.
  - *Качество* 0–100: скорость 50 баллов (полный балл от 50 Мбит/с), пинг 30 баллов (полный до 50 мс, ноль от 500 мс), стабильность 20 баллов (доступность за 24 ч). Шкалы настраиваются. Без замера скорости за сутки оценка неполная (≈, максимум 50). Переключение при выигрыше от 10 баллов.
- **Блоки приоритета**: серверы подписки по ключевым словам, подписка целиком, конкретный сервер, ключевые слова во всех подписках, самые стабильные, свои серверы. Условия блока: максимальный пинг, только на мобильной сети. В конце всегда «Любой рабочий». Возврат на блок выше — после 2 успешных проверок подряд.
- **Проверка пинга** во время работы каждые 15–120 с без пересоздания VPN-интерфейса.

### Скорость
- **Тест скорости** вручную: пакет 1 / 5 / 10 / 25 МБ с `speed.cloudflare.com`, серверы по одному через временное ядро.
- **Автопроверка** (только в режиме «Качество»): по счётчикам трафика ядра и детектору «заморозки»; при простое — лёгкая проверка 150 КБ раз в 30 с (при выключенном экране — раз в 5 мин). Если медленно — полный замер, затем кандидаты партиями по 3 (до 6). Переход, если кандидат быстрее в 1,5 раза и на 3 Мбит/с; иначе пауза 10 мин.

### Подключение
- **Раздельное туннелирование**: все приложения / только выбранные / кроме выбранных. Применяется без переподключения.
- **Российские сайты напрямую**: `.ru`, `.su`, `.рф`, российские сервисы и IP напрямую, заблокированные — через VPN. Базы встроены в APK и обновляются из релиза `rules`.
- Плитка в шторке (долгое нажатие открывает приложение), режим и пинг в уведомлении, поддержка «Постоянной VPN».

### Прочее
- **Статистика** в виде дашборда: время подключения, трафик, топ-5 серверов за период, журнал переключений.
- **Логи** приложения, ядра и падений в одном файле; просмотр, отправка, сохранение. UUID и ссылки маскируются.
- **Экран падения** с текстом ошибки, если приложение не смогло запуститься.
- **Обновление из приложения** с прогрессом загрузки.

## Устройство

```
app/src/main/java/com/mkred/xrayclient/
├── App.kt       запуск по этапам (сбой одного этапа не роняет приложение)
├── core/        LinkParser, XrayConfig, XrayCore (libv2ray), ServerSelector, Blocks,
│                Quality, SpeedTest, AutoCheck, Net, NetworkState, GeoRules
├── data/        Models, AppStore (data.json), Stats (stats.json), Subscriptions, InstalledApps
├── service/     XrayVpnService (VpnService + TUN → Xray), VpnState, QsTileService
├── log/         AppLog (файл логов, маскировка, запись падений)
├── update/      Updater (GitHub Releases)
└── ui/          Главная, Серверы, Источники, Статистика, Настройки и их компоненты
```

- Ядро — [AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite). CI скачивает `libv2ray.aar`, версия задаётся в `LIBXRAY_TAG` в `.github/workflows/build.yml`.
- Дескриптор TUN передаётся прямо во встроенный `tun`-вход Xray, tun2socks не нужен.
- Само приложение исключено из туннеля. Его запросы (подписки, обновления, автопроверка) идут через локальный HTTP-прокси ядра на `127.0.0.1` со случайным портом, логином и паролем, которые создаются при каждом запуске. Если VPN выключен или прокси недоступен — напрямую.
- Базы для обхода РФ — урезанные `geoip.dat` / `geosite.dat` из [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat) (`scripts/trim_geo.py`). Workflow `rules.yml` ежедневно обновляет их в пре-релизе `rules`.

## Сборка и обновления

При каждом пуше в `main` GitHub Actions (`build.yml`) собирает подписанный APK и публикует релиз `v1.0.<номер сборки>`. Приложение проверяет последний релиз и предлагает установить его.

### Секреты репозитория для подписи

| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 |
| `KEYSTORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Ключ должен оставаться одним и тем же, иначе Android не даст поставить обновление поверх установленной версии. Файлы ключа (`*.jks`, `*.keystore`) в репозиторий не коммитятся.
